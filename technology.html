03 / INVENTORY

Real-time inventory synchronisation

Single source of truth across every warehouse, platform, and sales channel. Sub-second propagation. Zero oversell guarantee.

01

Multi-source aggregation

Consolidate stock from owned warehouses, 3PL partners, FBT/Shopee Xpress/Lazada Logistics, and vendor-managed inventory into one virtual pool. Configurable allocation rules per platform, market, and channel.

02

Event-driven sync engine

Kafka-backed event pipeline processes order creation, cancellation, return, and warehouse receipt events in < 500ms median latency. Idempotent consumers guarantee exactly-once inventory deduction.

03

Platform-native buffers

Automatically maintains platform-specific safety buffers (TikTok Shop: 2%, Shopee: 3%, Lazada: 2%) and enforces per-SKU minimum display quantities to prevent race conditions during flash sales.

04

Bundle & kit decomposition

Virtual bundles and multi-component kits explode into component-level reservations at order time. Supports nested bundles, pre-pack configurations, and dynamic kit assembly from shared component pools.

05

Cross-dock & transfer routing

Inter-warehouse transfer suggestions generated nightly based on 14-day demand forecasts. Auto-creates transfer orders when regional stock falls below dynamic reorder points.

06

Audit trail & reconciliation

Immutable event log with cryptographic hashing. Daily automated reconciliation against platform-reported quantities and warehouse WMS snapshots. Drift alerts routed to Slack and PagerDuty.

04 / ORDER ROUTING

Intelligent order orchestration

Every order evaluated against real-time constraints — stock location, SLA, shipping cost, platform rules, and customer promise — to determine the optimal fulfilment path.

01

Ingestion & normalisation

Orders pulled via platform webhooks and scheduled API polls. Normalised into canonical schema with enriched buyer data, shipping tier, payment method, and promotional context.

02

Eligibility matrix

Evaluates warehouse proximity to delivery postcode, stock availability, platform SLA windows (TikTok: 24h, Shopee: 48h, Lazada: 48h), courier coverage, and special handling requirements (cold chain, hazmat, oversized).

03

Cost-optimised allocation

Solves constrained optimisation: minimise total landed cost (pick/pack + shipping + platform fee surcharges) subject to SLA and stock constraints. Uses pre-computed courier rate cards updated weekly.

04

Split & merge logic

Multi-item orders automatically split across warehouses when beneficial. Partial fulfilment supported with pro-rata platform fee allocation. Merge window (15 min) combines orders to same address for single shipment.

05

Label generation & handoff

Generates platform-compliant shipping labels, customs invoices (for cross-border), and packing slips. Pushes tracking numbers back to platforms via API within SLA. Integrates with Ninja Van, J&T, Janio, Kerry, and 12+ regional carriers.

06

Exception handling

Automated reroute on courier rejection, address failure, or stock discrepancy. Fallback to next-best warehouse with customer notification. Manual override queue for edge cases with full audit trail.

07 / SECURITY & DATA

Security & data principles

Commerce data is sensitive. We treat it as such. Architecture, processes, and culture aligned to protect merchant and consumer data at every layer.

Data minimisation & purpose limitation

We collect only what is necessary to operate the platform: OAuth tokens (encrypted at rest), order and product data for synchronisation, and anonymised usage telemetry. No consumer PII stored beyond what platforms require for fulfilment. Data retention policies enforced automatically: order data 24 months, logs 90 days, telemetry 13 months.

Zero-trust architecture

All internal communication mutual TLS. Service mesh (Istio) enforces least-privilege policies. No implicit trust zones. Database access via short-lived certificates. Secrets managed in HashiCorp Vault with automatic rotation. Employee access via SSO + hardware keys, just-in-time elevation with approval workflow.

01

Encryption

AES-256-GCM at rest (Cloud KMS managed keys). TLS 1.3 in transit with perfect forward secrecy. Field-level encryption for OAuth tokens, API keys, and PII. Key rotation every 90 days.

02

Compliance

SOC 2 Type II (in progress). PDPA Singapore compliant. ISO 27001 aligned controls. Platform-specific data processing addenda with TikTok, Shopee, Lazada. Cross-border transfer mechanisms for MY, PH, TH, ID, VN.

03

Incident response

24/7 on-call rotation. Mean time to acknowledge < 15 min. Automated containment playbooks for credential leak, data exposure, and platform API compromise. Post-incident reviews published internally within 5 business days.

04

Penetration testing

Annual third-party penetration test (CREST certified). Continuous automated scanning in CI/CD. Bug bounty programme via HackerOne. Critical findings remediated within 72 hours, high within 7 days.

05

Business continuity

Multi-AZ deployment in Singapore (AWS ap-southeast-1) with warm standby in Sydney (ap-southeast-2). RPO < 1 min, RTO < 15 min for core sync services. Quarterly failover drills. Platform webhook replay capability for 72h.

06

Vendor risk

All subprocessors assessed via SIG questionnaire. DPAs in place. Annual re-assessment. Current subprocessors: AWS, Cloudflare, SendGrid, Twilio, Segment, HackerOne, PagerDuty, Slack, Atlassian.
